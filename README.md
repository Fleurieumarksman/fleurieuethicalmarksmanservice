## Online enquiry form
The form uses FormSubmit to send enquiries directly to:
`admin@fleurieuethicalmarksmanservice.com.au`

On the first test submission, FormSubmit normally emails the destination address asking for one-time activation. Open that email and activate the form. After activation, website enquiries are delivered directly to the FEMS inbox.

## Updating the live GitHub Pages site
Upload/replace **all files and the assets folder** in the existing GitHub repository. Keep `CNAME` in the repository root. No DNS change should be required because the domain is already connected.

## Notes
